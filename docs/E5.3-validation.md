# E5.3 — consolidated physical validation

Status: preparation only. No target hardware result is implied.

Use the same EFI, OS build, monitor, cable and kext binary for every phase. Record the candidate commit and SHA-256 of the installed kext executable. Keep a known-good bootable EFI available. Do not install a candidate until E5.1/E5.2 integration is approved.

Compile the existing user-space probe:
```sh
xcrun swiftc tools/metal_probe.swift -o /tmp/wex-metal-probe
```

Run the collector once per phase:
```sh
bash tools/validate-e53.sh "$HOME/wex-e53" baseline /tmp/wex-metal-probe
bash tools/validate-e53.sh "$HOME/wex-e53" connected /tmp/wex-metal-probe
bash tools/validate-e53.sh "$HOME/wex-e53" reconnected /tmp/wex-metal-probe
bash tools/validate-e53.sh "$HOME/wex-e53" post-wake /tmp/wex-metal-probe
```
Between commands, manually connect HDMI, disconnect/reconnect, then sleep/wake. Stop if display corruption, hangs or panic occur. No automatic sleep or privileged writes.

| Observation | Acceptance |
|---|---|
| Internal panel | No artifacts; brightness adjustable |
| External HDMI | Stable image on connection and reconnection |
| HDMI audio | Audible stereo from selected external sink, not merely device enumeration |
| Wake | Internal and external images recover; HDMI audio audible again |
| Metal | Compute, render, linear texture and mipmap output verified on intended GPU before and after wake |
| Video | H264 and HEVC playback observed; hardware decoding requires separate evidence |
| Stability | At least 15 minutes of graphics use without visible corruption or hangs |

Record pass/fail/not-tested for each observation, including repeated wake cycles (three recommended). Collector exit codes describe commands, not physical success. Metal tests do not establish Metal 3 feature completeness. Review raw logs for identifiers before sharing. CI cannot substitute for target hardware.
