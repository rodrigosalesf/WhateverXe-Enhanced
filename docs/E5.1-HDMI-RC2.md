# E5.1 RC2: display audio research

References (research only, no imported code): [jkbuha report #124](https://github.com/b00t0x/WhateverXe/issues/124), [contribution #150](https://github.com/b00t0x/WhateverXe/issues/150), [diagnostic commit](https://github.com/jkbuha/WhateverXe-contrib/commit/4bd5cb951e96).

The 46A6 Tahoe report describes codec enumeration difficulties and a later experimental route involving codec discovery, pin mapping, ELD and stream binding. Replug remains unresolved. This is not qualification of 46A3 on Sequoia. The Acer has matching hda-gfx and analog outputs; digital codec identity and connector routing are not established.

## Gates before active implementation

1. Verify exact donor symbols and signatures for each supported OS; absent or ambiguous symbols fail closed.
2. Distinguish codec enumeration, verb response, ELD availability, engine publication and actual playback as independent milestones.
3. Derive connector and pin mapping from verified hardware evidence; never transplant a fixed 46A6 pin table blindly.
4. Validate EDID lengths/checksums and audio capability before generating ELD; test malformed and truncated inputs offline.
5. Keep kernel hooks disabled until ABI and hardware prerequisites can be verified. Do not read FIFO-backed registers in passive diagnostics.
6. Preserve E5 Metal and display paths; defer physical tests to E5.3. Hotplug and wake remain separate acceptance criteria.
