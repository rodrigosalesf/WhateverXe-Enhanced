# RC3 port review

Source: https://github.com/jkbuha/WhateverXe-contrib/commit/94b8fb6 (credit jkbuha; no code copied). Source describes 46A6, codec 8086281C, macOS 26 with SimpleHDA. Not verified on Acer 46A3 Sequoia.

Observed in source: codecCommand chooses first matching AppleHDAController and first IOHDACodecDevice, with default codec address 2; this is not sufficient to select the Intel digital codec. buildIntelPathMap pairs ordered pins with converters without checking connection-list edges. Manual hooks depend on fixed prologues, object offsets and vtable slots; prefix checks alone cannot establish layout. Delayed MMIO restoration requires verified mapping lifetime and cancellation. Discovery slot writes can partially succeed. Do not transplant these mechanisms blindly.

Port requirements: unique verified controller/codec identity and provider ownership, explicit codec address, digital widget capabilities and observed connection edges; reject ambiguity. Verify exact Sequoia ABI, object layouts and lifecycle before any active write. Keep existing graphics paths untouched. Physical tests deferred to E5.3. No functional fix claimed.
